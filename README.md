## 🔐 Security & Payments

This website is currently a frontend prototype.

- No payment information is collected.
- Checkout requests are directed to Discord.
- Orders and reviews are saved locally in the visitor's browser.
- Admin tools are not protected by secure authentication.
- Never publish Discord bot tokens, passwords, or private API keys.

A secure backend is required for shared orders, protected administration, verified discount codes, and payment processing.
